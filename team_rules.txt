1. Thống nhất tên file:
    -chữ thường
    -tiếng Anh
    -không dấu
    -không khoảng trắng
    -dùng "_" hoặc "-"
2. Thống nhất Commit Message:
    -Format "type: message"
3. Thống nhất Branch Naming:
    -Format "type/task-name"

Các type khuyên dùng:
    feat	      thêm tính năng mới
    fix	          sửa lỗi
    docs	      tài liệu
    refactor	  viết lại code
    data	      thêm/sửa dữ liệu
    model	      train/update model
    style	      format code
    test	      thêm test
    chore         việc vặt
